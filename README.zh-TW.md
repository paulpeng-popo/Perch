# Perch

[English](README.md) ｜ **繁體中文**

用你自己的帳號瀏覽 X（Twitter）的桌面 App，只看不碰：不會按讚、轉推、追蹤，也不會標成已讀。看到喜歡的圖片和影片，可以一鍵存成原圖、最高畫質，但請尊重智慧財產權。

> ⚠️ 基於網頁 API 實作，可能違反 X 的使用條款，瀏覽太兇可能被限流或鎖帳號，後果請自行負責。

## 功能

- 追蹤中、為你推薦、書籤、列表、個人檔案、對話串、搜尋
- 多人時間軸：把幾個帳號的推文合在一起看
- 媒體牆與看圖模式，一鍵下載原圖與影片
- 多帳號切換、RSS 訂閱、深淺色

## 下載

到 [Releases](../../releases) 下載你的系統的版本，解壓縮（Mac 是打開 dmg）後直接執行，不用安裝。

第一次打開如果出現安全警告：Windows 按「其他資訊」→「仍要執行」；Mac 對 Perch 按右鍵 →「打開」。

## 開始使用

打開 Perch →「設定」→「登入 X」，登入你的帳號就可以開始看了。

不用時把整個資料夾刪掉即可，電腦上不會留下其他東西。

## 快捷鍵

| 按鍵 | 作用 |
|---|---|
| `j` ／ `k` | 下一則／上一則推文 |
| `g` | 切換媒體牆 |
| `s` | 多選下載（`Esc` 取消） |
| `r` | 重新整理 |
| `Ctrl` ＋ `K` | 跳到搜尋框 |
| `←` `→` 或滾輪 | 看圖時換張 |
| 空白鍵 | 看圖時幻燈片 |
| `Z` | 看圖時放大 |
| `D` | 看圖時下載這張 |

## 從原始碼執行

需要 Node.js 20 以上。

```
npm install
npm run app      # 開桌面版
npm start        # 或用瀏覽器開
npm run dist     # 打包
```
