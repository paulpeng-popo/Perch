      新增帳號
      
            
      
                
      開一個 x.com 登入視窗，你自己登入後會自動加進來。登入視窗用完就丟，不會留在電腦上，也不用在 x.com 按登出（登出會讓這組登入失效）。
      
                
                
      
            
      
            
      
                手動貼 cookie
                
      在瀏覽器登入要加的帳號 → 按 F12 →「應用程式／Application」→ Cookie → https://x.com，複製 auth_token 和 ct0 的值貼到下面。也可以把整串 Cookie 標頭直接貼進任一格。
      
                
      要加第二個帳號時，在 x.com 先登出原本的帳號再登入另一個（或用無痕視窗），才拿得到另一組 cookie。不要在 x.com 按「登出」來切換已經加進來的帳號：登出會讓那組 cookie 失效。用無痕視窗登入、拿完 cookie 直接關掉視窗最安全。
      
                
                
                
            
      
            
      基於網頁 API 實作，可能違反 X 的使用條款，瀏覽太兇可能被限流或鎖帳號，後果請自行負責。
      
        
      

        
      
            
      下載
      
            
            
      存成 資料夾/帳號/推文ID_第幾張.副檔名，已存在的會略過。
      
            
      
                
                
                
            
      
        
      

        
      
            
      App 資料
      
            
      帳號、設定、內建瀏覽器的快取都只放在這個資料夾。不用 Perch 時把整個 app 資料夾刪掉，電腦上就不會留下任何東西（下載的圖片影片除外）。
      
            
      
            
        
      

        
      
            
      X 前端解析
      
            
      X 改版時 API 的編號會變，伺服器會自動重新解析；如果某個頁面一直出錯，可以手動重來一次。
